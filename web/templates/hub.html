PriceAI Model Detector

这是 PriceAI 使用的独立 API 中转模型检测服务。用户入口在 PriceAI 主站； 本服务负责接收检测任务、运行协议探针、生成报告 JSON 和可分享报告页。

基于 Veridrop · AGPL-3.0-or-later · API Key 不落盘 · 证据报告不等于商家背书

打开 PriceAI 模型检测入口 → 查看 PriceAI 检测服务源码
Service Boundary 独立后端

主站负责入口和展示

PriceAI 主仓保留 `/api-transit/detector` 的用户界面、站点上下文和报告展示壳。 它通过 `NEXT_PUBLIC_TRANSIT_DETECTOR_API_BASE_URL` 调用本服务。

Detector Runtime 执行层

服务负责敏感检测

本仓库负责 Claude、OpenAI Chat Completions、OpenAI Responses 和 Gemini 兼容接口的真实请求检测、 任务状态、报告 JSON、报告图片和 Turnstile 校验。

Attribution AGPL

保留上游归属

本服务 fork 自 `canarybyte/veridrop`，继续采用 AGPL-3.0-or-later。 PriceAI 修改记录和上游归属见仓库里的 README 与 NOTICE。

HTTP contract

PriceAI 主站使用 POST /api/detect/claude、 POST /api/detect/openai-chat、 POST /api/detect/openai-responses、 POST /api/detect/gemini 提交任务，并通过 /api/status/{job_id} 与 /api/result/{job_id}.json 读取结果。完整契约见仓库中的 PRICEAI_INTEGRATION.md。
